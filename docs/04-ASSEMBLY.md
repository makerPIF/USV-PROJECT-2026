## 1. 전자부 배선

핀 배치와 전원 계통은 [01-HARDWARE.md](01-HARDWARE.md#4-esp32-핀-배치)에 있습니다. 요약하면:

- **신호** — ESC ×2(GPIO25/26), MPU6050(I2C 21/22), GPS(UART2 16/17), iBUS(GPIO4), 전압(GPIO34), 부저(GPIO27)
- **전원** — 3S → 메인 스위치 → XT60 분배 → ESC ×2 / UBEC #1(ESP32계) / UBEC #2(공유기·카메라)
- **GND** — 전부 ESP32 GND에 공통으로 모읍니다

> [!CAUTION]
> **ESC 두 개의 BEC 빨간선을 반드시 뽑아 절연하세요.**
> 두 ESC의 5V 출력이 서로 싸우다 한쪽이 고장납니다. 5V는 UBEC에서만 받습니다.

### 배선 작업 순서

1. **브레드보드에서 먼저** — ESP32·MPU6050·GPS·수신기를 꽂고 센서값이 나오는지 확인합니다.
   **모터는 아직 연결하지 않습니다.**
2. **만능기판으로 이전** — 동작을 확인한 뒤에 납땜으로 옮깁니다
3. **열수축튜브** — 모든 연결부에 씌웁니다. 배 안은 진동과 습기가 있는 환경입니다
4. **케이블 길이 여유** — 해치를 열어 전자부를 꺼내 작업할 수 있을 만큼 남깁니다

## 2. 펌웨어 업로드

### ESP32 NodeMCU — `firmware/usv_main_esp32/`

1. **보드 추가** — 환경설정 → 추가 보드 관리자 URL에
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json` 입력 →
   보드 매니저에서 `esp32` 설치
2. **라이브러리 설치** — 라이브러리 매니저에서
   `ArduinoJson`, `Adafruit MPU6050`, `TinyGPSPlus`, `ESP32Servo`, `IBusBM`
3. **ZIP 라이브러리 2개** — GitHub에서 [`ESPAsyncWebServer`](https://github.com/me-no-dev/ESPAsyncWebServer)와
   [`AsyncTCP`](https://github.com/me-no-dev/AsyncTCP)를 ZIP으로 내려받아
   스케치 → 라이브러리 포함하기 → .ZIP 라이브러리 추가
4. **보드 설정** — `ESP32 Dev Module` / Flash Size `4MB` / Partition `Default 4MB with spiffs`
5. **업로드** — 진행이 멈추면 보드의 `BOOT` 버튼을 누른 채 기다립니다
6. **확인** — 시리얼 모니터 `115200`에서 Wi-Fi 접속·IP·IMU 보정 메시지 확인

### [카메라 A] XIAO ESP32S3 Sense — `firmware/usv_cam_xiao/`

1. **카메라 결합** — 확장 보드를 "딸깍" 소리가 날 때까지 끝까지 밀어 넣습니다
2. **보드 선택** — `XIAO_ESP32S3`
3. **PSRAM** — 도구 → PSRAM → **`OPI PSRAM`**
   ⚠️ 이 설정을 빠뜨리면 영상이 QVGA 이상으로 안 나옵니다
4. **파티션** — `Huge APP (3MB No OTA/1MB SPIFFS)`
5. **확인** — 브라우저에서 `http://192.168.8.30/stream`

### [카메라 B] ESP32-CAM AI-Thinker — `firmware/usv_cam_esp32cam/`

**둘 중 하나만 쓰면 됩니다.** 주소 체계가 같아서 GCS는 고칠 필요가 없습니다.

> [!WARNING]
> **이 보드에는 USB 단자가 없습니다.** USB-TTL(FTDI) 어댑터가 따로 필요합니다.

1. **업로드용 배선**

   | ESP32-CAM | USB-TTL |
   |---|---|
   | `5V` | `5V` ※ 3.3V로 주면 부팅에 실패합니다 |
   | `GND` | `GND` |
   | `U0R` (GPIO3) | `TX` |
   | `U0T` (GPIO1) | `RX` |
   | `IO0` | `GND` ※ **업로드할 때만** |

2. **보드 설정** — `AI Thinker ESP32-CAM` / PSRAM `Enabled` /
   Partition `Huge APP (3MB No OTA/1MB SPIFFS)` / Upload Speed `115200`
3. **업로드 순서** — IO0–GND 연결 → `RESET` 한 번 → 업로드 →
   "Hard resetting..." 이 뜨면 **IO0–GND 분리** → `RESET` 한 번
4. **운용 배선** — `IO0`는 아무 데도 연결하지 않습니다. `5V`는 UBEC #2에서 받습니다

> [!CAUTION]
> ESP32-CAM은 **전원에 매우 민감**합니다. 5V 2A 이상을 직접 공급하고,
> `5V`–`GND` 사이에 **470 µF 전해 커패시터**를 달아 두세요.

> 세 파일 모두 상단의 `WIFI_SSID`, `WIFI_PASS`, `LOCAL_IP`, `GATEWAY` 네 줄만 바꾸면
> 다른 공유기에서도 그대로 동작합니다.

## 3. 추진계 설치

> [!IMPORTANT]
> **순서가 중요합니다.** ESC 설정 → 회전 방향 확인 → 그 다음에 프로펠러.
> 프로펠러를 먼저 달면 설정 중에 다칩니다.

1. **ESC 3D 모드 설정** — [01-HARDWARE §7](01-HARDWARE.md#7-esc를-후진-가능하게-만들기).
   프로펠러를 뺀 채로 두 개 모두 설정합니다
2. **모터 마운트 고정** — `MotorMountOptions.stl` 중 하나를 골라 선체 안에 에폭시+볼트로 고정
3. **구동축 연결** — 커플러로 모터축(3.17 mm)과 구동축(4 mm)을 잇습니다.
   **축 정렬**을 맞추세요. 어긋나면 진동이 생기고 스터핑 튜브가 더 샙니다
4. **그리스 충전** — 스터핑 튜브 안에 선박용 그리스를 가득 채웁니다
5. **회전 방향 확인** — 프로펠러를 **뺀 상태**로 전원을 넣고 GCS에서 전진 명령.
   축이 도는 방향을 보고, 반대면 모터 3가닥 중 아무 2가닥을 바꿔 끼웁니다
6. **프로펠러 장착** — 마지막에. **좌현 CW, 우현 CCW**(또는 반대로, 둘이 다르기만 하면 됩니다)

## 4. 조립 순서 12단계

전자부를 **먼저 책상에서 완전히 검증**하고, 그 다음에 배에 넣습니다.
배에 다 넣은 뒤에 문제를 찾으면 전부 다시 뜯어야 합니다.

| # | 단계 | 내용 |
|---|---|---|
| 1 | 선체 출력·접합·방수 | [03-HULL.md](03-HULL.md). 접착과 코팅 경화에 며칠 걸리므로 가장 먼저 |
| 2 | 책상 위 배선 | 브레드보드에 ESP32·센서·수신기. 시리얼 모니터로 값 확인. **모터 없이** |
| 3 | ESC 3D 모드 설정 | 프로펠러를 뺀 채로. 회전 방향까지 확인 |
| 4 | 공유기 설정 | [05-NETWORK.md](05-NETWORK.md). `.20`, `.30` 으로 붙는지 확인 |
| 5 | GCS 연결 시험 | `index.html` 을 열어 그래프가 움직이고 영상이 나오는지. **여기까지가 전자부 완성** |
| 6 | 납땜 정리 | 만능기판으로 옮기고 열수축튜브 |
| 7 | 구동축 설치·밀봉 | **선체를 닫기 전에.** 그리스 충전, 양면 에폭시 |
| 8 | 전자부 수납 | 해치 아래 공간에. 배선은 케이블 그랜드 + 에폭시로 |
| 9 | 데크 조립 | 데크 3개 접합 → 선체에 결합 |
| 10 | 안테나·카메라 | 안테나는 마스트에 수직으로, 카메라는 선수에서 15° 아래를 보도록 |
| 11 | 배터리 고정 | 벨크로 스트랩으로 데크 중앙 **낮은 곳**에. 무게중심이 낮고 가운데여야 안 뒤집힙니다 |
| 12 | 무게중심 확인 | 완성된 배를 손가락 두 개로 들어 좌우·앞뒤 균형을 봅니다 |

## 5. 시험 절차 5단계

다섯 단계를 순서대로. **앞 단계를 통과하지 못하면 다음으로 넘어가지 않습니다.**

| 단계 | 장소 | 확인 항목 | 통과 기준 |
|---|---|---|---|
| **1 · 지상** (프로펠러 제거) | 교실 책상 | 센서값, GCS 연결, 시동/정지, ESC 회전 방향, 페일세이프 | Wi-Fi를 껐을 때 1.5초 안에 모터가 멈출 것 |
| **2 · 추력 측정** | 물통 + 저울 | 프로펠러를 물에 담그고 스로틀별 추력·전류 기록 | 모터가 손으로 만질 수 있는 온도를 유지할 것 |
| **3 · 부양 시험** | 큰 대야·수조 | 흘수, 좌우 균형, 전자부 침수 여부 (모터는 끔) | 흘수 적정, 24시간 뒤 내부 건조 |
| **4 · 근거리 조종** | 수영장·잔잔한 못 | 10 m 로프를 매고 전진·후진·좌우·제자리 회전 | 모든 방향 제어 정상, 로프 없이 회수 가능 |
| **5 · 통달거리 시험** | 개활 수면 | 50 m씩 늘려가며 RSSI·손실·지연 기록 | "주의" 등급이 뜨는 거리를 그날의 **운용 한계**로 정할 것 |

### 2단계 — 추력 측정을 이렇게 합니다

수중 프로펠러는 공중에서 돌려도 의미가 없습니다. 물에 담가야 합니다.

1. 큰 물통에 물을 채우고, 선체(또는 모터+축 조립체)를 고정합니다
2. 저울 위에 올리거나, 줄로 저울에 연결해 당기는 힘을 잽니다
3. 스로틀 25 / 50 / 75 / 100 % 에서 추력(gf)과 전류(A)를 기록합니다
4. **각 단계마다 20~30초 돌린 뒤 모터를 만져 봅니다**

측정값을 `hardware/USV_BOM.xlsx` 의 `추진성능계산` 시트 B12·B13 에 넣으면
운용 시간과 여유율이 우리 기체 기준으로 다시 계산됩니다.

> [!TIP]
> 5단계 시험 데이터를 GCS로 기록해 엑셀로 저장하면 **거리–RSSI 그래프**를 그릴 수 있습니다.
> 안테나를 바꾸기 전후로 두 번 측정해 비교하면 그 자체로 훌륭한 탐구 보고서가 됩니다.

## 6. 안전 수칙

### 프로펠러

- 펌웨어를 올리거나 시험할 때는 **프로펠러를 빼 두는 것이 기본**입니다
- 배터리를 꽂기 전에 "프로펠러 주변 비었나?"를 **소리 내어** 확인하는 습관을 들이세요
- 시동(ARM) 상태에서는 배를 손으로 들지 않습니다

### 리튬폴리머 배터리

- 충전은 반드시 **사람이 지켜보는 상태**에서, 방염 가방 안에서
- 부풀었거나 찌그러진 배터리는 즉시 폐기합니다. 되살리려 하지 마세요
- 3.4 V/셀(10.2 V) 아래로 방전시키지 않습니다. GCS가 자동으로 막아줍니다
- 보관은 3.8 V/셀 부근(스토리지 모드)에서

### 수상 활동

- 물가에서는 **구명조끼를 착용**합니다. 배를 건지려다 물에 들어가는 상황이 실제로 자주 생깁니다
- 지도교사 없이 진행하지 않습니다
- 회수 계획을 먼저 세웁니다 — 긴 로프, 뜰채, 필요하면 보트
- 수영·낚시하는 사람 근처, 물살이 있는 곳, 바람이 센 날은 피합니다
- **돌아올 몫의 배터리를 남겨 두고 회항**합니다

> [!CAUTION]
> **운항 전 최종 점검 5가지**
> ① 프로펠러·구동축 고정 ② 배터리 12 V 이상 ③ RC 조종기 켜짐·비상정지 확인
> ④ GCS 통신 등급 "양호" 이상 ⑤ 해치 닫힘·케이블 관통부 밀봉
