## 1. 출력물 확인 — 키 9개를 버리지 마세요

STL 10개를 실제로 열어 안에 든 덩어리를 세어 보면 이렇습니다.

| 파일 | 내용물 |
|---|---|
| `Float_Part1` | 선체 구간 **2개** (좌·우) — 속이 빈 구조 |
| `Float_Part2` | 선체 구간 2개 + **정렬 키 2개** |
| `Float_Part3` | 선체 구간 2개 |
| `Float_Part4` | 선체 구간 2개 + **부속 2개**(87 × 24 × 46 mm) + **정렬 키 2개** |
| `Deck_Part1` | 데크 1개 + **정렬 키 2개** |
| `Deck_Part2` | 데크 1개 + 키 구멍 + **정렬 키 2개** |
| `Deck_Part3` | 데크 1개 + 키 구멍 |
| `Cockpit` | 선실 2개 + **정렬 키 1개** |
| `Hatch` | 해치 뚜껑 1개 + 링 1개 |
| `MotorMountOptions` | 모터 마운트 **2종** (40×45×32, 30×45×32) — 둘 중 하나만 씁니다 |

> [!WARNING]
> **작게 떨어져 나오는 조각 9개는 서포트가 아니라 정렬 키입니다.**
> 대부분 `4.8 × 19.8 × 9.8 mm` 크기의 납작한 막대입니다.
> 출력물을 베드에서 떼면서 부스러기로 알고 버리기 쉬우니, 출력이 끝나면 **먼저 봉투에 모아 두세요.**
> 키 없이 맞추면 선체가 미세하게 어긋나 접합면에 틈이 생기고, 그 틈이 그대로 누수 지점이 됩니다.

`Float_Part4` 의 부속 2개는 형상이 복잡한 것으로 보아 샤프트 스트럿이나 러더로 보입니다.
설계자의 [설치 영상](https://youtu.be/WdNshlzVaMU)에서 어느 위치에 들어가는지 먼저 확인하세요.

## 2. 출력 설정 — 방수는 슬라이서에서 시작됩니다

FDM 출력물은 **기본적으로 방수가 되지 않습니다.** 벽 사이 미세한 틈으로 물이 스며듭니다.
나중에 코팅으로 덮기 전에, 출력 단계에서 최대한 촘촘하게 뽑아 두는 것이 훨씬 쉽습니다.

| 항목 | User Guide | 권장 | 이유 |
|---|---|---|---|
| 재질 | PLA 또는 PETG | **PETG** | PLA는 물을 머금고, 햇빛·차 안 더위에 휘어집니다 |
| 레이어 높이 | 0.2 mm | 0.2 mm 유지 | — |
| 벽 두께 | 선체 3겹 | **선체 4겹** (0.4 노즐 기준 1.6 mm) | 3겹은 물이 배어 나옵니다 |
| 바닥/윗면 | — | **각 5겹** | — |
| 채움 | 10 % | 10 % 자이로이드 | 가볍고 사방으로 튼튼 |
| 노즐 온도 | — | **권장치 상단 +5~10 ℃** (PETG 240~245 ℃) | 레이어 접착이 방수를 좌우합니다 |
| 냉각 팬 | — | **PETG 30~50 %** | 너무 식히면 층 사이가 벌어집니다 |
| 솔기(Seam) | — | **Aligned 또는 Rear** | Random은 미세 구멍을 만듭니다 |
| 브림 | 2 mm | 2 mm 유지 | 설계자 권장 그대로 |
| 서포트 | Cockpit, Deck_Part2·3만 | 그대로 | — |

슬라이서에서 **"Ensure vertical shell thickness"**(수직 셸 두께 보장)를 켜 두세요.
완만한 곡면에서 벽이 얇아지는 것을 막아 줍니다.

> 출력을 시작하기 전에 **선체 한 구간만 먼저 뽑아 물을 채워 보세요.**
> 30분 뒤 물이 배어 나오면 벽을 5겹으로 올리거나 온도를 더 높입니다.
> 2 kg을 다 뽑고 나서 알게 되는 것보다 낫습니다.

## 3. 접합 — 키 맞춤과 에폭시

### 접착제 선택

User Guide는 "acrylic glue"라고만 적어 두었습니다. 실제로 쓸 만한 것은 다음과 같습니다.

| 접착제 | 평가 |
|---|---|
| **30분 경화 2액형 에폭시** | ★ **권장.** 틈을 메우고, 방수되고, PLA·PETG 모두에 붙습니다. 굳기 전 위치를 맞출 시간도 넉넉합니다 |
| 순간접착제(CA) | 빠르지만 부서지기 쉬움. 구조 접합에는 부적합. 임시 고정용으로만 |
| 아크릴계 접착제 | 쓸 수 있으나 에폭시보다 틈 메움이 약합니다 |
| 아세톤 | **PLA·PETG에는 듣지 않습니다**(ABS 전용). 쓰지 마세요 |
| 글루건 | 전자부 고정용. 선체 접합에는 금물 — 더우면 녹습니다 |

### 접합 순서

> [!IMPORTANT]
> **안쪽에서 손이 닿는 동안 안쪽을 먼저 봉하세요.**
> 선체 한 쪽을 4개 구간으로 이어 붙이면, 마지막 구간을 붙이는 순간 내부 접근이 끊깁니다.
> 각 이음매는 **붙인 직후 그 자리에서** 안쪽 필렛까지 마무리하고 다음 구간으로 넘어갑니다.

1. **가접(Dry fit)** — 접착제 없이 키를 끼워 맞춰 봅니다. 뻑뻑하면 키를 사포로 조금 갈아 냅니다.
   억지로 밀어 넣으면 소켓이 터집니다.
2. **접합면 다듬기** — 80방 사포로 맞닿는 면을 **평평하게** 갈아 냅니다.
   첫 레이어의 코끼리발(elephant foot)이 남아 있으면 그만큼 틈이 됩니다. 이어서 120방으로 거칠기를 만듭니다.
3. **탈지** — 이소프로필알코올로 접합면을 닦습니다. 손기름이 남으면 접착력이 떨어집니다.
4. **방향 표시** — 유성펜으로 위·아래와 좌·우를 표시합니다. 에폭시를 바른 뒤에는 헷갈릴 시간이 없습니다.
5. **에폭시 도포** — **양쪽 면 모두**에 얇게 바릅니다. 키와 소켓 안에도 조금 넣습니다.
6. **압착·고정** — 눌러 끼우고 삐져나온 에폭시를 닦아 냅니다.
   마스킹 테이프를 이음매 둘레로 팽팽하게 감아 30분간 고정합니다.
7. **안쪽 필렛** ★ — **이것이 진짜 방수층입니다.**
   굳기 시작하면(15~20분) 이음매 안쪽을 따라 에폭시를 한 줄 더 돌립니다.
   손이 안 닿으면 긴 막대 끝에 스펀지를 붙여 밀어 넣습니다. 일회용 주사기도 좋습니다.
8. **완전 경화** — 다음 구간으로 넘어가기 전에 최소 **2시간**, 가능하면 하룻밤 둡니다.

### 조립 순서 권장

```
① 좌현 선체 : 선미 구간 → 중간 → 중간 → 선수   (이음매 3곳, 매번 안쪽 필렛)
② 우현 선체 : 같은 방식
③ 각 선체 단독 누수 시험  ← 여기서 반드시 한 번 걸러냅니다 (7장)
④ 구동축 관통부 설치 + 밀봉  ← 선체를 닫기 전에!
⑤ 데크 3개 접합 → 선체에 결합
⑥ 선실(Cockpit) → 해치 링
⑦ 전체 표면 코팅 (4장)
```

③과 ④를 건너뛰지 마세요. 데크까지 올린 뒤에는 고칠 방법이 없습니다.

## 4. 표면 방수 — 에폭시 코팅

User Guide는 "선저에 얇게 레진 한 겹"이라고 했지만, USV는 전자장비를 싣고 오래 떠 있으므로
**수선(waterline) 위로 데크까지 전체**를 코팅하는 편이 안전합니다.

| 방법 | 평가 |
|---|---|
| **코팅용 투명 에폭시 레진** | ★ 권장. 가장 확실하고 단단합니다 |
| XTC-3D | 3D 출력물 코팅 전용. 바르기 쉽고 비쌉니다 |
| 우레탄 바니시(스프레이) | 간편하지만 3~4겹 필요하고 내구성이 떨어집니다 |
| 유리섬유 + 에폭시 | 이 크기에는 과합니다 |

### 작업 순서

1. **샌딩** — 80방으로 레이어 선을 지우고, 180방으로 마무리합니다.
   User Guide의 80방은 시작일 뿐입니다. 거친 표면에 코팅하면 기포가 남습니다.
2. **탈지** — 이소프로필알코올로 닦고 완전히 말립니다.
3. **예열** — 드라이어로 선체를 살짝 데웁니다(40 ℃ 정도).
   출력물 안의 공기가 미리 빠져나와 코팅 중 기포가 적게 생깁니다.
4. **1차 도포** — 스펀지로 **얇게** 펴 바릅니다. 두껍게 바르면 흘러내려 뭉칩니다.
5. **경화** — 24시간. 서두르지 마세요.
6. **중간 샌딩** — 320방으로 가볍게. 광을 죽여 2차 도포가 잘 붙게 합니다.
7. **2차 도포** — 1차와 같은 방식으로.

> 선체 **안쪽**도 손이 닿는 범위까지 발라 두면 좋습니다.
> 바깥 코팅이 깨져도 한 겹이 더 남습니다.

코팅으로 늘어나는 무게는 선체 전체에 **100~150 g** 정도입니다. 부력 계산에 넣어 두세요.

## 5. 해치 — 여닫으면서 물을 막는 유일한 곳

`Hatch` 는 뚜껑과 링 2개로 되어 있습니다(각 116 × 116 × 17 mm).
배터리를 갈고 전자부를 손보려면 매번 열어야 하므로, **접착해 버릴 수 없는 유일한 방수 지점**입니다.

1. **링을 데크에 고정** — 에폭시로 완전히 붙이고, 안쪽에 필렛까지 돌립니다. 이쪽은 영구 접합입니다.
2. **개스킷** — 다음 중 하나
   - **네오프렌/EPDM 폼 테이프** (두께 3 mm, 폭 10 mm) — 가장 간단하고 잘 됩니다
   - **TPU로 출력한 O링** — 쇼어 95A, 단면 Ø3 mm
   - 실리콘 튜브를 잘라 링 모양으로 접착
3. **조임** — M3 나사 4개를 대각선 순서로 조입니다.
   데크 쪽에는 **열삽입 황동 인서트**를 넣으세요. 출력물 나사산은 몇 번 여닫으면 뭉개집니다.
4. **실리콘 그리스** — 개스킷에 얇게 바릅니다. 밀착이 좋아지고 개스킷이 들러붙지 않습니다.

> [!TIP]
> 해치는 **수선에서 가장 먼 곳, 가능한 한 높은 위치**에 둡니다.
> 파도가 데크를 넘더라도 해치까지는 닿지 않도록 하는 것이 설계의 핵심입니다.

## 6. 관통부 — 배가 실제로 가라앉는 지점

선체가 새서 가라앉는 경우보다, **구멍 주변에서 새서** 가라앉는 경우가 훨씬 많습니다.

### 구동축 관통 — 이 배에서 가장 어려운 부분

축이 돌면서 물을 막아야 하므로 완전 밀봉이 불가능합니다. 조금씩 새는 것을 **전제로** 설계합니다.

| 할 일 | 설명 |
|---|---|
| 스터핑 튜브에 그리스 충전 | **선박용 그리스**를 튜브 안에 가득 채웁니다. 운항 전마다 보충 |
| 튜브와 선체 사이 밀봉 | 튜브가 선체를 지나는 자리를 **안쪽·바깥쪽 양쪽에서 에폭시로** 메웁니다 |
| 축 정렬 | 모터축과 구동축이 일직선이어야 합니다. 어긋나면 진동이 생기고 그만큼 더 샙니다 |
| 빌지 대비 | 선체 바닥에 **스펀지를 깔아** 들어온 물을 머금게 합니다 |
| 배수 플러그 | 선미 낮은 곳에 M6 나사 + O링. 운항 후 물을 빼냅니다 |

> [!IMPORTANT]
> 구동축 설치와 밀봉은 **선체를 닫기 전에** 끝내야 합니다.
> 데크를 올린 뒤에는 안쪽에서 손이 닿지 않습니다.

### 케이블 관통 (안테나·센서선)

가장 확실한 방법은 **에폭시 포팅**입니다.

```
① 케이블 지름보다 2~3 mm 큰 구멍을 뚫습니다
② 케이블을 통과시키고 안쪽에서 여유를 둡니다
③ 구멍 안쪽을 에폭시로 가득 채웁니다 (주사기 사용)
④ 경화 후 바깥쪽도 한 번 더 메웁니다
```

실리콘 실란트보다 에폭시가 낫습니다. **실리콘은 PETG에 잘 붙지 않아** 시간이 지나면 떨어집니다.

케이블 그랜드(PG7)를 쓴다면, 그랜드 **나사부 자체도** 에폭시나 테플론 테이프로 함께 밀봉해야 합니다.
그랜드는 케이블 둘레만 잡아 줄 뿐, 데크와 그랜드 사이는 막아 주지 않습니다.

### 에어 프로펠러로 바꾸는 경우

선저의 구동축 구멍을 **반드시 막아야 합니다.** 구멍 지름에 맞는 마개를 출력해 끼우고,
**안쪽과 바깥쪽 양쪽에서** 에폭시로 메웁니다. 선체를 이어 붙이기 **전에** 하세요.

## 7. 누수 시험 3단계

> [!CAUTION]
> **전자부를 넣기 전에** 끝내야 하는 시험입니다. 순서를 바꾸지 마세요.

### 1단계 · 빛 시험 (조립 직후)

어두운 방에서 선체 안에 밝은 LED(휴대폰 손전등)를 넣고 바깥에서 봅니다.
이음매나 벽에서 빛이 새면 그 자리가 물이 들어올 자리입니다. 코팅 전에 에폭시로 메웁니다.

### 2단계 · 물 채우기 시험 (선체 단독, 데크 결합 전)

선체 한 쪽을 세워 물을 가득 채우고 **30분** 둡니다.
바깥에 마른 휴지를 대고 눌러 보면 미세한 스밈도 잡아낼 수 있습니다.

> 이 시험은 실제 운항보다 **가혹한** 조건입니다. 물기둥의 압력이 흘수보다 훨씬 높기 때문입니다.
> 여기서 통과하면 물에 띄웠을 때는 거의 문제가 없습니다.

### 3단계 · 24시간 부유 시험 (완전 조립 후, 전자부 없이)

선체 안에 **전자부와 같은 무게의 추**(물병, 공구 등)를 싣고 욕조나 큰 통에 24시간 띄웁니다.
해치를 열어 안쪽에 물기가 있는지 확인합니다. 마른 휴지 몇 장을 넣어 두면 판별이 쉽습니다.

구동축이 있는 배는 **약간의 스밈이 정상**입니다. 바닥 스펀지가 축축한 정도면 통과,
물이 고일 정도면 그리스를 더 채우거나 밀봉을 보강하세요.

**여기까지 통과한 뒤에** 전자부를 넣습니다.

## 8. 부력과 중량 확인

이 선체는 원래 가벼운 RC 요트용입니다. 우리 USV는 공유기·카메라·큰 배터리까지 실으므로
**설계자가 상정한 것보다 무겁습니다.** 반드시 직접 확인하세요.

### 측정 방법

1. 조립이 끝난 선체(전자부 없이)를 물에 띄우고 **흘수선을 유성펜으로 표시**합니다
2. 500 g씩 추를 더하며 그때마다 흘수선을 표시합니다
3. 데크 아래 **30 mm**까지 잠기는 시점의 무게가 **안전 적재 한계**입니다

### 예상 중량

| 항목 | 무게 |
|---|---:|
| 출력물 (필라멘트 2.3 kg) | 2,300 g |
| 에폭시 접합 + 코팅 | 150~200 g |
| 전자부 (ESP32·센서·공유기·카메라·배선) | 약 400 g |
| 모터 2기 + ESC + 구동축·프로펠러 | 약 400 g |
| 배터리 3S 5000 mAh | 약 400 g |
| 체결구·기타 | 약 150 g |
| **합계** | **약 3.8 ~ 3.9 kg** |

> [!WARNING]
> 측정한 안전 적재 한계가 **4 kg 미만**이면 경량화가 필요합니다.
> 채움(infill)을 낮추거나, 배터리를 3S 3000 mAh로 줄이거나, 선실(Cockpit)을 생략하는 방법이 있습니다.
> 건현(수면에서 데크까지의 높이)이 부족한 배는 작은 파도에도 물을 뒤집어씁니다.

선체 안의 빈 공간에 **EPP/EPS 폼을 채워 두면**, 어딘가 깨져 물이 들어와도 가라앉지 않습니다.
회수 실패를 막는 가장 값싼 보험입니다.

## 9. 선체 체크리스트

**출력 단계**

- [ ] PETG, 선체 벽 4겹, 노즐 온도 상단, 솔기 Aligned
- [ ] 한 구간 시험 출력 후 물 채우기 시험 통과
- [ ] **정렬 키 9개를 따로 모아 보관**

**접합 전**

- [ ] 선체 샤프트 구멍 지름 실측 → 스터핑튜브 규격 확정
- [ ] 배수 플러그 구멍 가공
- [ ] 접합면 80방 → 120방 샌딩, IPA 탈지

**접합**

- [ ] 선체별로 선미→선수 순서, 이음매마다 **안쪽 필렛**
- [ ] 각 이음매 2시간 이상 경화
- [ ] 선체 단독 **빛 시험** 통과
- [ ] 선체 단독 **물 채우기 시험 30분** 통과
- [ ] **구동축 관통부 설치 + 양면 에폭시 밀봉** (선체 닫기 전)

**마감**

- [ ] 80 → 180방 샌딩, 예열, 에폭시 2회 코팅 (중간 320방)
- [ ] 해치 링 접착 + 안쪽 필렛, 열삽입 인서트 4개
- [ ] 개스킷 + 실리콘 그리스
- [ ] 케이블 관통부 양면 에폭시 포팅

**최종**

- [ ] 추를 싣고 **24시간 부유 시험** 통과
- [ ] 흘수선 측정, 안전 적재 한계 기록
