## 1. 모터 선정 — 왜 1000KV인가

선체 설계자(ViewCG)의 User Guide는 **"A2212 또는 지름 39 mm 이하 모터"** 라고만 적고
KV는 지정하지 않았습니다. A2212는 같은 이름으로 1000 / 1400 / 2200KV 가 팔리므로,
어느 것을 고르느냐가 성능을 가릅니다.

### 결론 — **A2212 1000KV**

| | 1400KV | **1000KV (채택)** |
|---|---:|---:|
| 3S 공칭(11.1 V) 무부하 | 15,540 rpm | **11,100 rpm** |
| 만충(12.6 V) 무부하 | 17,640 rpm | **12,600 rpm** |
| 같은 전류에서 토크 | 기준 | **약 1.4배** |

### 근거

**수중 프로펠러는 고회전을 싫어합니다.**
이 배는 배수량형 쌍동선으로 1~2 m/s 로 가는 배입니다. 그렇게 느린 배에
15,000 rpm 을 물속에서 돌리면 **공동현상(cavitation)** 이 생깁니다.
프로펠러 날 뒷면의 압력이 물의 증기압 아래로 떨어져 기포가 생기고,
프로펠러가 물 대신 거품을 밀게 되어 추력이 오히려 떨어집니다.

**토크가 필요한 쪽입니다.**
KV가 낮으면 같은 전류에서 토크가 큽니다. 물은 공기보다 약 800배 무거워
프로펠러를 돌리는 데 힘이 많이 드는데, 1000KV 쪽이 이 부하를 더 잘 끌어갑니다.

### 제원 (공급사마다 다릅니다)

| 항목 | 값 | 비고 |
|---|---|---|
| 축 지름 | **3.17 mm** | 커플러 선택의 기준 |
| 셀 수 | 2–3S (일부 2–4S 표기) | 3S 사용 |
| 최대 전류 | **13 A** ~ 18.8 A | 공급사마다 제각각 |
| 최대 전력 | 150 W ~ 209 W | 보수적으로 150 W 기준 |
| 크기 / 무게 | 약 40 × 27.7 mm / 50~60 g | — |

> [!WARNING]
> **같은 "A2212 1000KV"라도 권선이 다릅니다.** 구매한 판매처의 스펙 페이지에 적힌
> 최대 전류를 기준으로 삼고, 보수적으로 가려면 낮은 쪽(13 A)으로 계산하세요.
> 13 A 기준이면 모터당 144 W, 두 기 합쳐 288 W 입니다. 30 A ESC로는 넉넉합니다.

> [!IMPORTANT]
> **모터축 지름을 캘리퍼스로 직접 재 보세요.** A2212는 보통 3.17 mm 지만
> 4 mm 축으로 나오는 물량도 있습니다. 커플러 주문이 여기서 갈리고, 틀리면 통째로 못 씁니다.

## 2. 추진 방식 — 수중 샤프트 vs 에어 프로펠러

이 선체는 원래 **수중 추진용**으로 설계됐습니다. User Guide가 요구하는 부품이 그 증거입니다.

> 2 x RC boat driveshaft (200mm x 8mm)

모터는 선체 안에 건조한 상태로 두고, 구동축이 선저를 뚫고 나가 물속 프로펠러를 돌리는 방식입니다.
`MotorMountOptions.stl` 도 그 전제로 만들어진 마운트입니다.

| | **수중 샤프트 (채택)** | 에어 프로펠러 (대안) |
|---|---|---|
| 모터 | A2212 1000KV | A2212 1400KV |
| 프로펠러 | 황동 3엽 40 mm (M4) | 8045 (8×4.5″) 항공용 |
| 추진 효율 | 높음 | 낮음 |
| 선저 관통부 | **있음** — 가장 어려운 방수 지점 | 없음 |
| 수초·부유물 | 프로펠러에 감김 | 영향 없음 |
| 소음 | 조용함 | 큼 |
| 안전 | 회전부가 물속 | 15,000 rpm 노출 — 가드 필수 |
| 이 선체와의 궁합 | 설계자 의도 그대로 | 선저 구멍을 막아야 함 |

> [!NOTE]
> **"A2212는 수중에 부적합"이라는 말은 모터를 물에 담그는 경우입니다.**
> 구동축 방식은 모터가 선체 안에 건조하게 들어가므로 해당하지 않습니다.
> 물에 잠기는 것은 프로펠러와 축뿐입니다.

에어 프로펠러로 바꾸려면 → [03-HULL.md](03-HULL.md#6-관통부--배가-실제로-가라앉는-지점)의
"샤프트 구멍 막기"를 **선체 접합 전에** 반드시 하세요.

## 3. 카메라 보드 — 둘 중 무엇을 쓸까

영상 모듈은 **ⓐ XIAO ESP32S3 Sense** 와 **ⓑ ESP32-CAM AI-Thinker** 두 가지를 모두 지원합니다.
펌웨어 파일만 골라 올리면 되고, 주소 체계(`192.168.8.30` · `/stream` · `/control`)가 같아서
**GCS는 전혀 고칠 필요가 없습니다.**

| 항목 | ⓐ XIAO ESP32S3 Sense | ⓑ ESP32-CAM AI-Thinker |
|---|---|---|
| 가격 | 약 32,000원 | 약 9,000원 (+ USB-TTL 7,000원) |
| USB 단자 | **있음** — 케이블만 꽂으면 업로드 | 없음 — FTDI 어댑터 필수 |
| 업로드 난이도 | 쉬움 | IO0–GND 점프 필요 |
| 외장 안테나 | 기본 제공 | 가능하지만 **납땜 개조** 필요 |
| 크기 / 무게 | 21 × 17 mm / 약 5 g | 40 × 27 mm / 약 20 g |
| PSRAM | 8 MB | 4 MB |
| 전원 민감도 | 둔감 | **매우 민감** (470 µF 커패시터 권장) |
| 발열 | 적음 | 많음 (방열판 권장) |
| 플래시 LED | 없음 | **있음** (GPIO4) — 저조도 회수용 탐조등 |
| 펌웨어 | `usv_cam_xiao.ino` | `usv_cam_esp32cam.ino` |

**이렇게 고르세요.**

- 처음 만드는 팀, 중학생이 직접 납땜한다면 → **ⓐ XIAO**. 실패할 구석이 적습니다.
- 예산을 아껴야 하거나 여러 대를 만든다면 → **ⓑ ESP32-CAM**. USB-TTL은 팀당 1개면 됩니다.
- 이미 학교에 ESP32-CAM이 굴러다닌다면 → 당연히 **ⓑ**.

## 4. ESP32 핀 배치

| 핀 | 연결 대상 | 선 색 (일반) | 비고 |
|---|---|---|---|
| `GPIO25` | 좌현 ESC 신호 | 흰색 또는 노랑 | PWM 50 Hz |
| `GPIO26` | 우현 ESC 신호 | 흰색 또는 노랑 | PWM 50 Hz |
| `GPIO21` | MPU6050 SDA | — | I2C 400 kHz |
| `GPIO22` | MPU6050 SCL | — | — |
| `GPIO16` | NEO-8M 의 **TX** | — | 서로 엇갈려 연결(RX↔TX) |
| `GPIO17` | NEO-8M 의 **RX** | — | 9600 bps |
| `GPIO4` | FS-iA6B 의 iBUS(SENS) 단자 | — | 신호선 1가닥만 |
| `GPIO34` | 전압 분배 회로 중점 | — | 입력 전용 핀 |
| `GPIO27` | 부저 (+) | — | — |
| `3V3` | MPU6050 VCC | 빨강 | 5V도 되지만 3.3V 권장 |
| `VIN` | UBEC #1 의 5V | 빨강 | — |
| `GND` | **모든 GND 공통** | 검정 | ESC·수신기·센서 전부 |

> [!CAUTION]
> **가장 흔한 실수 — ESC 두 개의 BEC(빨간 선)를 동시에 연결하지 마세요.**
> 두 ESC의 5V 출력이 서로 다른 값을 밀어내며 싸우다가 한쪽이 고장납니다.
> ESC 신호 커넥터 3가닥 중 **빨간 선을 뽑아서 절연**하고, 흰색(신호)과 검정(GND)만 연결하세요.
> 5V는 UBEC에서 받습니다.

## 5. 전원 계통

```
3S LiPo ── 메인 스위치 ── XT60 분배 ┬── ESC ×2 (11.1V 직결, BEC 빨간선 제거)
                                     │
                                     ├── UBEC #1 → 5V ┬── ESP32 (VIN)
                                     │                 └── MPU6050 · NEO-8M · 수신기
                                     │
                                     └── UBEC #2 → 5V ┬── 미니 공유기
                                                       └── 카메라 보드
```

**UBEC를 두 개 쓰는 이유** — 공유기와 카메라는 순간 소비전류가 크게 출렁입니다.
ESP32와 같은 5V 선을 쓰면 그 출렁임에 컨트롤러가 리셋될 수 있어, 전원 계통을 아예 갈라 놓습니다.

UBEC 용량은 각 **3 A 이상**. ESP32-CAM을 쓴다면 UBEC #2 쪽 5V–GND 사이에
**470 µF 전해 커패시터**를 추가하세요.

## 6. 배터리 전압 측정 회로

ESP32의 ADC는 3.3 V까지만 읽으므로 11.1 V를 저항 두 개로 나눠 넣습니다.

```
배터리(+) ── 100 kΩ ──┬── 22 kΩ ── GND
                      │
                      └── GPIO34
```

분배비 `(100+22) / 22 = 5.545` → 만충 12.6 V일 때 GPIO34에는 2.27 V가 걸립니다.
펌웨어의 `VBAT_DIV_RATIO` 값이 이 5.545입니다.

멀티미터 실측값과 GCS 표시값이 다르면 `VBAT_CAL` 을 `실측 ÷ 표시` 로 넣어 보정하세요.
예: 실측 12.4 V, 표시 12.0 V → `VBAT_CAL = 1.033`

## 7. ESC를 후진 가능하게 만들기

보통의 드론용 ESC는 한 방향으로만 돕니다. 후진을 하려면 ESC 펌웨어의
**Bidirectional(3D) 모드**를 켜야 합니다. 이 한 단계를 빼먹으면 배가 앞으로만 갑니다.

### 3D 모드에서의 신호 규약

| 펄스 폭 | 동작 |
|---|---|
| `1000 µs` | 최대 후진 |
| `1500 µs` | **정지 (중립)** |
| `2000 µs` | 최대 전진 |

펌웨어의 `PULSE_NEUTRAL / PULSE_FWD_MAX / PULSE_REV_MAX` 가 이 값들입니다.
중립 부근 ±30 µs(`PULSE_DEAD`)는 일부러 아무 출력도 내지 않는 구간으로 두어,
손을 뗐을 때 모터가 떨지 않게 합니다.

### 설정 절차

1. **BLHeliSuite 설치** — 검색해서 `BLHeliSuite`(BLHeli_S용)를 받습니다. 윈도우 전용입니다.
2. **ESC 연결** — USB 링커를 PC와 ESC 신호 커넥터에 연결하고, ESC에는 배터리로 전원을 넣습니다.
   (링커가 없다면 아두이노 나노에 `4-way interface` 스케치를 올려 대신 쓸 수 있습니다.)
3. **Read Setup** — 인터페이스를 고르고 `Connect` → `Read Setup`.
4. **Motor Direction = Bidirectional** — 이것이 핵심 항목입니다.
5. **Programming by TX = Off** — 켜 두면 조종 신호로 설정이 바뀔 수 있습니다. 반드시 끕니다.
6. **Low RPM Power Protect = On** — 저속에서 모터가 헛도는 것을 막아줍니다.
7. **Write Setup** — 저장하고, 나머지 ESC 한 개도 똑같이 설정합니다.
8. **회전 방향 확인** — 프로펠러를 뺀 상태로 전원을 넣고 GCS에서 전진 명령을 줍니다.
   반대로 돌면 `Bidirectional Reversed` 로 바꾸거나, 모터 3가닥 중 **아무 2가닥**을 바꿔 끼웁니다.

> [!WARNING]
> 구입한 ESC가 BLHeli_S 펌웨어가 아니면(예: SimonK, 일반 Skywalker) 이 설정이 불가능합니다.
> 상품 설명에 **"BLHeli_S"** 가 있는지 사기 전에 꼭 확인하세요.
